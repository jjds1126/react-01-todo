# Lecture 01: Todo List
* 간단한 할 일 목록(Todo List)을 관리할 수 있는 웹 애플리케이션 실습 프로젝트입니다. 웹 실습 강의 및 자바스크립트 기초 학습 용도로 제작되었습니다.

## 주요 기능
* **할 일 추가** : 새로운 할 일을 입력하여 목록에 추가합니다.
* **할 일 목록 조회** : 등록된 전체 할 일 목록을 확인합니다.
* **완료 상태 토글** : 클릭 시 할일의 완료(체크/체크 해제)를 전환합니다.
* **할 일 삭제** : 완료되었거나 필요 없는 할 일을 목록에서 삭제합니다.
## 기술 스택 (Tech Stack)
* **Frontend** : HTML5, CSS3, JavaScript(Es6+)
* **Package Manager / Build Tool** : pnpm / Vite
